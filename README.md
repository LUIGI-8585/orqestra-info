# OrQestra V2 — dokumentacja integracji z Allegro

Publiczna, statyczna dokumentacja aplikacji OrQestra V2 używana podczas rejestracji integracji z REST API Allegro.

Repozytorium zawiera wyłącznie treść informacyjną strony. Nie zawiera kodu aplikacji, konfiguracji, sekretów, tokenów ani danych kont Allegro.
